# Phase 4A Decision

**B. EXTERNAL_CONFIRMATION_FEASIBLE_WITH_PROTOCOL_ADAPTATION**

Bitbrains fastStorage and Rnd independently provide CPU utilization, RX+TX network throughput, active memory usage, and disk-write throughput at a verified 300-second cadence. They can test the frozen S1/S2/M1 boundary questions without outcome-driven target selection.

The label is not “exact replication”: TimeTrack samples near 42.285 seconds, external fields use documented physical units where TimeTrack rate units are partly unknown, and elapsed-time leads/contexts must be remapped. These adaptations are prospective and do not alter the scientific comparison.

Materna is compatible secondary evidence but not pristine because of prior DynAPM exposure. Alibaba, Google, and Azure are structurally incompatible with the required four-target tuple. New TimeTrack collection remains desirable but is `UNKNOWN_REQUIRES_CONTACT`, so it does not supersede the feasible Bitbrains route.

This decision authorizes only a later protocol-freeze task. It does not authorize training or a new architecture.
