## 2. Primary entity endpoint and signs

Resource order is CPU, THROUGHPUT, MEMORY, DISK_WRITE. Let a(m,b,e,r,f,h,s) be native MAE on the **exact same test origins** for model m, block b, entity e, resource r, fold f=1..5, prescribed horizon h=1..K_b, seed s=0..4. Each MAE first averages absolute errors over that cell's origins; there is no pooling of predictions across models or weighting by the cell's test-row count.

Define A(m,b,e,r,s) = (1/5) sum_f [(1/K_b) sum_h a(m,b,e,r,f,h,s)], then A(m,b,e,r)=(1/5) sum_s A(m,b,e,r,s). Thus horizons, folds and seeds receive equal weights in that order; finite complete rectangular grids make the averaging commute. **Aggregate native MAEs within entity before logging.** Define D_b,e,r(C:R)=ln[A(C,b,e,r)/A(R,b,e,r)]. Positive means candidate error is higher; negative means lower. The group effect is the arithmetic mean of D across entities. exp(mean D) is the geometric mean entity MAE ratio. These do not replace v1 MacroMAE gains; also report native equal-entity MacroMAEs and their gain separately as descriptive endpoints.

FS and Rnd are separate inferential groups, 35 entities each. For Materna, define D_M,e,r = (D_T1,e,r + D_T2,e,r + D_T3,e,r)/3, then average across the same 35 VMs. Equal temporal weights are applied to log effects, not to unlike native units or raw predictions. Individual traces are descriptive supporting panels, not three independent replications. TimeTrack averages its seven entity effects descriptively, without p-values or inferential CIs.

All terms in an interaction or difference-of-effects must use the identical entity, complete folds/horizons/seeds and the same entity-level A. Define I_e,r = D_e,r(M1:S2) − D_e,r(M0:S1). Equivalently I=ln A_M1−ln A_S2−ln A_M0+ln A_S1. I>0 means the all-input sharing penalty exceeds the own-input sharing penalty. This is one interaction-like contrast, not two duplicated hypotheses or causal identification.

### Zeros, missingness and failure

Zero cell MAEs are legitimate and included in A. If either entire A in a registered contrast is zero, record the extended ratio/log (zero numerator only: 0/−∞; zero denominator only: +∞/+∞; both zero: undefined). Do not add epsilon, silently exclude that entity, or change to cell logs. The finite primary mean/CI/test for that resource/group is **not estimable under the registered log endpoint**, and its planned testing slot receives p=1 for multiplicity accounting; report exact zero-aggregate counts and native-MAE differences descriptively. Do not call an unavailable test evidence for equality. Use this same rule for all terms of interaction/intervention contrasts.

Any missing origin, failed fit, nonfinite prediction, incomplete seed/fold/horizon grid or mismatched support makes that planned arm incomplete. Never average available pairs only, replace an entity, impute results or use a different comparator seed count. Quarantine evidence; only an explicitly documented technical repair and same-identity retry may restore completion, without tuning from test outcomes. Otherwise report the arm incomplete and assign its prelisted testing slots p=1. No unregistered complete-case primary result. Undefined auxiliary persistence skill at zero persistence MAE is separately counted and does not invalidate a finite primary MAE.

## 3. Hypotheses and multiplicity

CPU sharing and all interaction tests have no predicted sign. An interaction is detected by the adjusted two-sided test; sign specifies its direction. Absence of detection is not equivalence. No “mostly”, “material” or unspecified magnitude cutoff defines success.

## 4. Resampling and inferential boundary

Paired cluster bootstrap: 10,000 replicates, NumPy PCG64 seed **20261110**. Generate entity-index matrices once in fixed group order FS, Rnd, Materna; n=35 draws with replacement for each replicate, independent matrices per group. Reuse each group's matrix across resources, arms, contrasts and correlation calculations. Each sampled entity carries its complete paired folds, horizons and seeds; Materna carries all three traces together. Do not resample cells or seeds as independent units. The inferential unit is the source-specific entity, with the retained exchangeability/eligible-population assumption explicit; this is not an IID claim about folds or all cloud systems.

Report the 2.5/97.5 percentile bootstrap CI for the arithmetic mean entity log effect (and exponentiate its endpoints for ratio display). Marginal intervals are not multiplicity-adjusted intervals. For the two-sided bootstrap test of zero, use the centred bootstrap distribution: p=(1+count(|theta_star−theta_hat|>=|theta_hat|))/10001, including exact equality. Use linear interpolation for percentiles. In each fixed family sort raw p-values ascending, tie-break by lexicographic test ID. For rank j in a family of m, Holm adjusted p is min(1,max_{k<=j}[(m-k+1)p_(k)]); BH adjusted p is min(1,min_{k>=j}[m p_(k)/k]). Map back to original IDs. Reject at adjusted p<.05; keep unavailable slots at raw p=1. Entity index order is frozen cohort rank, using exact string IDs. This is a prespecified approximate cluster-bootstrap test, not an exact randomisation test; report that limitation at n=35. For correlation replace theta with Spearman rho using average ranks; any constant original variable makes that test unavailable. Any constant-variable bootstrap replicate is counted as an exceedance for the p-value and as undefined for interval reporting; if any such replicate exists, do not publish a numeric percentile correlation interval. Report its count. No post-hoc resampling-method switch.

Power/precision is not guaranteed: v1 has only three seeds, no M0 results, and only 35 selected external entities. The locked five-seed budget is a fixed design decision, not an empirical power conclusion. Stage01 finite cell-log variances inform sensitivity/limitations but are not variance estimates of this new aggregate-then-log estimand. No further v1 calculation is a registration prerequisite. The prior v1 variability summaries are planning context only. No required power target or minimum effect size is fabricated.

## 5. Gradient diagnostic protocol

Run on newly trained M0 and M1 core final-fit trajectories, all six blocks and five seeds. The exact shared parameters are the encoder's weight_ih_l0, weight_hh_l0, bias_ih_l0, bias_hh_l0 and the corresponding four l1 tensors, flattened in this named order. Exclude all heads, task weights and optimizer state. Task loss is the unweighted scaled MSE for one resource, averaged over origins and all horizons, before the joint 1/4 factor, clipping or any optimizer step.

Let E be the core joint-selected final epoch. Save three scheduled diagnostic slots: epoch0, ceil(E/2), E. Slots remain three even when epochs coincide; label duplicate checkpoint epochs and never treat them as independent checkpoints. The primary statistic uses slot E only; other slots and M0 diagnostics are descriptive. Extended checkpoint-control training (§6) must not move the primary diagnostic slot beyond E.

At each slot form eight independently keyed A/B batch pairs, batch size128 with replacement from legal outer-training origins only. Keys: SHA-256 of UTF-8 `fgcs-v03|block|exact_entity_id|fold|seed|slot|pair_index|A_or_B`, interpret first eight digest bytes little-endian as PCG64 seed. Draw origin-index integers uniformly. A and B are independent reproducible draws; overlap is permitted. Freeze exact ordered origin IDs and hashes. All four tasks see the same A or B origins. Windows may overlap temporally: this control estimates within-partition minibatch variation, not independent-observation uncertainty.

Clone model tensors/buffers onto CPU float32; eval mode disables dropout. Enable gradients on the clone, never load diagnostic gradients into live parameters. At each batch pair extract four task gradients on A and four on B with autograd.grad (8 vectors). No stochastic layers or optimizer calls; detach results. Record and compare live model/buffer/optimizer/.grad/Python/NumPy/Torch RNG state hashes before/after; any change fails the diagnostic. Do not advance the training loader. Run diagnostics outside measured baseline fit timing and record their cost separately.

For a batch pair define cross-conflict C=(1/6) sum_{i<j} 1[g_i(A) dot g_j(A)<0]. Same-task noise floor N=(1/4) sum_i 1[g_i(A) dot g_i(B)<0]. The **single primary compatibility statistic** is excess conflict K = mean over eight pairs of (C−N), range −1..1; higher values indicate more cross-task conflict relative to same-task minibatch conflict. K is a descriptive reference-adjusted contrast, not a variance estimator or an unbiased correction for gradient noise; cross-task dots use the same A origins whereas same-task dots compare independent A/B draws. Exact zero dot product is non-conflicting. A repeat of an identical deterministic batch is only a repeatability check, not this noise floor.

If any required gradient has exactly zero L2 norm, do not replace it with epsilon or label its cosine zero. Mark that pair K unavailable; record which task/checkpoint. Do not average seven available pairs in place of eight for the primary score. Average the complete eight-pair K over five folds and five seeds to obtain each entity's M1 K; for Materna average the three complete block scores. Any missing component makes the gradient association family slot unavailable (p=1); it does not erase valid prediction endpoints. Secondary outputs: individual cross/same-task cosines, dot products, norms, norm ratios and zero counts, separately by task/pair/slot. Pairwise compatibility matrices are exploratory. No shuffled labels, artificial noise task or task replacement control.

Exact logical diagnostic budget: 910 entity-fold groups ×5 seeds ×2 models ×3 slots ×8 pairs ×8 task gradients = **1,747,200 task-gradient extractions**, 27,300 checkpoint slots and 218,400 batch pairs; **zero new training fits**. Repeated epochs still have distinct slot-specific batch keys. Association uses the final-slot scores only. This sizable cost is fixed; no outcome-driven diagnostic sampling expansion.

## 6. Checkpoint and intervention controls: fixed reduced design

To bound secondary cost, use FS and Rnd only, all 35 existing VMs per environment, all five folds and seeds **0,1,2**. Match comparators to exactly those same three core seeds; do not compare three-seed interventions with five-seed core averages. No Materna or TimeTrack intervention inference is scheduled.

**Checkpoint control:** in each corresponding M1 inner trajectory, save the earliest best per-task validation-MSE epoch among epochs actually observed under the joint early-stopping rule. This tests task-specific selection on a common observed trajectory, not unlimited task-specific training. Record the joint-selected epoch E and four task epochs E_r. During the corresponding core final trajectory train once to max(E,E_CPU,E_THROUGHPUT,E_MEMORY,E_DISK_WRITE), saving those states. Fix the primary prediction checkpoint at E and task-specific predictions at E_r. Materialise outer-test data only after the entire trajectory is finished; evaluate each prespecified deployment choice once. No outer-test validation or selection. Thus **zero additional fit trajectories**, but explicitly extra training epochs beyond E can occur. Do not count this additional work as the primary fit's cost. Store four logical target checkpoint requests per identity (4,200 requests across 1,050 identities); identical epochs may share one physical file. Report both logical deployed networks (four) and physical unique checkpoints, compared with one jointly selected M1 model.

**PCGrad-M1:** same H64 model/data/initialisation schedule. On each training batch compute four unweighted task gradients over shared encoder parameters. For each task use an independently seeded permutation of the other tasks, initialise h_i=g_i and successively project h_i against immutable original g_j: if ||g_j||²>0 and h_i·g_j<0, set h_i ← h_i−(h_i·g_j/||g_j||²)g_j. Otherwise leave it unchanged. No task may use another task’s already projected gradient. Average the four projected encoder gradients. Heads receive their ordinary contribution from the mean task loss. Then clip all model gradients globally to1 and Adam-step. Permutation generator is isolated and keyed by training seed/epoch/batch; its draws cannot perturb baseline loaders. Separate joint-validation-MSE early stopping and fixed-epoch final refit. No PCGrad hyperparameter search.

**GradNorm-M1:** fixed alpha=1.5, as used by [Chen et al. (2018), §5.2/Table 1](https://proceedings.mlr.press/v80/chen18a/chen18a.pdf), a literature precedent rather than a universal optimum. No tuning. Equations (1)–(2) and Algorithm 1 govern the update. W is the concatenation of **all four trainable second-layer encoder tensors**, weight_ih_l1, weight_hh_l1, bias_ih_l1, bias_hh_l1. Both biases are trainable; flattening their gradients into the L2 norm is mathematically valid. No heads, first-layer weights or weight-optimizer parameters enter W.

Define L_i as scaled resource MSE divided by four, so the canonical summed objective J=Σ_i w_i L_i reduces exactly to the baseline mean MSE at unit weights. Initialise w_i=1. From the first ordinary training minibatch at t=0, before either update, save its L_i(0) using the same training-mode forward (no separate eval calibration). At each minibatch, set q_i=L_i(t)/L_i(0), r_i=q_i/mean(q), G_i=||∇_W(w_i L_i)||₂ and target_i=stop_gradient(mean(G) r_i^1.5). Use Σ_i |G_i−target_i| to differentiate only w, treating targets as constants. Compute both this gradient and the model gradient of J at the **same pre-update** model and weights; detach w in the model gradient and model derivatives in the weight objective. Apply the weight update first with separate Adam .025 (paper §5.1), then the model update with the already computed model gradient, baseline Adam .001 and clip1. Finally rescale updated w by 4/Σw. Never recalculate the model gradient using newly updated weights.

No v0.2 positivity clamp, epsilon, or alternative initial loss. Abort the identity on nonpositive initial reference loss, zero mean q, nonfinite values or a nonpositive proposed weight, retaining failure evidence; no modified algorithm or retry with other settings. Use the zero subgradient at absolute-value/norm ties. Maintain the baseline unweighted mean validation-MSE early stopping, seed schedule and equal-loss M1 comparator. Loss scaling, optimiser choices, gradient clipping, scope and early stopping are explicit study settings; the balancing equations and update order are canonical, not a bespoke balancing rule.

## 7. Empirical transfer experiments

Same fixed reduced scope: FS/Rnd, 35 each, five folds, three seeds0..2. For each input scope (own-input/shared size1 encoder; all-input/shared size4 encoder), train **six unordered two-task subsets** and **four three-task subsets obtained by omitting one of four tasks**. Each subset has one shared encoder and only its retained heads, H64, equal mean retained-task losses. Own-input heads consume their own history only; all-input models keep **all four input channels even when an output task is omitted**, so leave-one-out removes supervision, not a predictor. L, supports and scaler are unchanged; single-target reference is S1 for own-input, common-context S2 for all-input. Each subset receives its own inner early stopping on equal mean retained-task scaled MSE and fixed-epoch refit. No extra context or capacity tuning.

For target i in subset T define transfer benefit F_i(T)=ln[A(independent-reference_i)/A(shared-T target_i)] using §2, restricted to seeds0..2. F>0 favours sharing. Pairwise directed affinity F_i({i,j}) is read for both targets of each trained pair (12 directed cells per environment/scope). Leave-one-out performance F_i(R\{j}) is defined for i≠j (12 cells); report these against independent references. Incremental supervision contribution Q_i,j=ln[A(shared R\{j},target_i)/A(shared R,target_i)] for i≠j, positive when adding task j reduces target i MAE. The full shared reference is the corresponding M0/M1 three-seed core slice, same L/support, with its own baseline early stopping. Q includes changed head count, loss normalisation and epoch choice; it is empirical transfer, not isolated task causality.

BH tests apply to the registered F matrices only; Q matrices are descriptive. Pairwise: 2 scopes ×6 subsets ×70 entities ×5 folds ×3 seeds = **12,600 inner +12,600 final**. Leave-one-out: 2×4×70×5×3 = **8,400 inner +8,400 final**. No extra single-task or full-shared reference fits. Logical deployed per-entity complement is six pair models or four triple models per scope; do not call a head one independently deployed model. No outcome-dependent pair selection.
