# FGCS / Elsevier submission requirements (verified)

- **Access date:** 2026-08-05
- **Primary source:** [Future Generation Computer Systems — Guide for authors](https://www.sciencedirect.com/journal/future-generation-computer-systems/publish/guide-for-authors) (ScienceDirect / Elsevier)
- **Journal:** Future Generation Computer Systems (FGCS)

## Verified requirements

| Topic | Verified rule |
|-------|----------------|
| Article type | Full Length Article |
| Layout | Strictly **double column**, **single spaced** (LaTeX permitted for double-column) |
| Page limit | **≤18 pages** including figures, tables, and references |
| Abstract | Concise, factual, **≤250 words**; stand alone; avoid references |
| Keywords | **6–10** English keywords |
| Highlights | Separate editable file; filename contains “highlights”; **3–5** bullets; each **≤85 characters** including spaces |
| Data availability | Data statement **required** at submission (Option C research-data instructions apply) |
| Reference style | Numbered citations (CAS / journal style via `cas-model2-names`) |
| Supplementary material | Encouraged; cite in text; submit with manuscript; not typeset by production |
| Peer review | **Single anonymized** review process (minimum typically two reviewers) |
| Title page | Author names, affiliations, corresponding author details required (single anonymized ⇒ keep identities in manuscript) |
| Figures | Separate files; captions required; **no generative-AI figure creation/alteration** |
| LaTeX sources | Editable `.tex` source required; PDF alone is not an acceptable source file |
| Generative AI | Must declare generative AI / AI-assisted tools used in manuscript preparation; tools are **not** authors; section title: “Declaration of generative AI and AI-assisted technologies in the manuscript preparation process” |
| Competing interests | Declaration required |
| Funding sources | Funding statement expected; use standard “no specific grant…” wording only if verified |
