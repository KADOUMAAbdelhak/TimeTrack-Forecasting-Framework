# Licence scope

Unless otherwise noted, original research code identified as project-authored
code is licensed under Apache-2.0. Third-party materials retain their respective
licences and terms.

The Apache-2.0 grant in `LICENSE` applies only to the original research source
files explicitly listed in `PROJECT_AUTHORED_CODE.txt` at this checkpoint.
The list identifies code scope; it does not invent or transfer copyright
ownership or replace an existing file-specific third-party notice. No new
copyright-holder names are asserted. Existing notices must be retained.

## Exclusions

This code licence does **not** relicense:

- TimeTrack, Bitbrains or Materna datasets, raw copies, or source-derived
  materials that remain governed by upstream rights/terms;
- Elsevier CAS LaTeX template, class, style or BST files;
- manuscript text, article figures, the supplement or other publication material;
- third-party/vendor code, libraries, binaries or dependencies;
- legacy/imported files whose ownership is not clearly established, including
  `old_fgcs_rejected/`;
- any other file not expressly identified by the code-scope list.

In particular, a code licence does not grant dataset redistribution rights,
article/publication rights, or rights over a dependency merely because the code
imports it. Results/provenance records and data are not included in the code
grant merely because they are stored next to a listed script. These boundaries
do not add restrictions to the Apache-2.0 grant for the listed original code.

See `NOTICE` for the verified source-specific references and acknowledgements.
The scope list deliberately excludes `manuscript/`, third-party templates and
uncertain legacy code. Historical execution seals and source bytes are unchanged;
the code grant is attached through this explicit list rather than rewriting
sealed source headers.
